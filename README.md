# Password Generator

## Description
This project is a simple Password Generator application developed using Python. It generates random passwords based on the length specified by the user. The password contains a combination of uppercase letters, lowercase letters, numbers, and special characters.

## Features
- Allows users to specify the desired password length.
- Generates random passwords.
- Includes uppercase and lowercase letters.
- Includes numbers and special characters.
- Displays the generated password on the screen.

## Technologies Used
- Python
- Random module
- String module

## How to Run
1. Install Python on your system.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run the following command:

   ```bash
   python password_generator.py
   ```

5. Enter the desired password length when prompted.
6. View the generated password on the screen.

## Example Output

```text
Enter the desired password length: 12
Your generated password is: aB7@mK2!pQ9#
```

Note: The output will vary each time the program runs.

## Learning Outcomes
- Understanding Python's built-in modules.
- Working with user input.
- Using loops and random selection.
- Manipulating strings and characters.

## Disclaimer
This project is created for educational purposes. For generating passwords for real accounts, use Python's `secrets` module instead of `random` for security-sensitive applications.
